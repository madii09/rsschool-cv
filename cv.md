## 💡 Code Example

Solution of the Codewars task _"Valid Parentheses"_:

```ts
function validParentheses(parens: string): boolean {
  let balance = 0;

  for (const char of parens) {
    if (char === '(') balance++;
    if (char === ')') balance--;
    if (balance < 0) return false;
  }

  return balance === 0;
}
```
